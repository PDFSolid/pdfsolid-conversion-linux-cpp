PDFSolid Conversion SDK v1.3.0 Release Date: 25 November 2026
=====================================================

New Features

Word to PDF:
- Supports generating PDF bookmarks from headings or from Word bookmarks.
- Supports specifying the output page range, such as "1-3,5,7-9".
- Supports keeping document properties such as title, author, subject and keywords.
- Supports unsupported-feature diagnostics: when a document contains a feature that may affect fidelity, the reason is reported.
- Supports exporting native Word decoration lines as editable PDF annotations.
- Supports rendering EMF and WMF vector metafiles, preserving geometry, clipping, lines and text.
- Supports gradient, pattern and picture fills, as well as picture color effects.
- Supports ruby (phonetic guide) text and section-level vertical text.
- Supports many list numbering formats, including circled digits, full-width, kana, Korean and Chinese counting formats.
- Supports positioning, text wrapping and stacking order of floating objects.
- Supports headers, footers, footnotes, sections, columns, page numbers, tables and paragraph borders inside cells.

Enhanced Features

Core:
- Added image-to-image format conversion; original images are kept as-is when OCR is turned off.
- Added frame-by-frame conversion of multi-page TIFF files, with page range selection.
- Added page size options for image conversion: match the image resolution to a standard paper size, or specify the output page width and height.
- Added a table recognition model profile option to choose between high accuracy and balanced.
- Reduced peak memory usage when converting to images; it no longer grows with the page count.

PDF to Word:
- Improved recognition of list bullets drawn as graphics, special characters and Wingdings or Symbol glyphs, with bullet size matching the source document.
- Improved row and column positions, borders and shading for ruled, sparsely ruled and incomplete-line tables.
- Improved editability: similar vector paths are merged to reduce lag when paging, zooming and editing in Word.
- Improved editable restoration of vector graphics: curves and clipped shapes are no longer split into polylines or converted to images.

PDF to Excel:
- Sets the Excel paper size from the page size, fixing abnormally increased pagination after conversion.

OCR and AI:
- Upgraded the table recognition model with a new balanced profile, incremental model package loading and profile switching.

Issues Addressed

Core:
- Improved conversion stability: fixed a crash at process exit, and a crash when converting OFD and dual-layer PDF for pages without a background image.
- Number parsing and formatting no longer depend on the system locale.
- Fixed missing or wrong characters caused by character maps conflicting with embedded fonts, ligatures mapped to empty values, and overprinted text.
- Improved restoration of word spaces: rebuilt spaces are assigned only to their own line, and blanks covered by text are no longer treated as word spaces.
- Fixed text completely covered by a gradient-filled rectangle still being treated as body text.
- Fixed an entire GIF image being lost in certain cases.
- Fixed multi-page TIFF version compatibility, out-of-bounds access, per-frame resolution and cancellation.
- Fixed blurry small images with semi-transparent masks.
- Improved font size and transparency retention of free text annotations, and unified the page position of link annotations.

PDF to Word:
- Improved header, footer and page number handling; fixed overlapping footer digits and header-area text hidden under color blocks.
- Fixed an extra page appearing in the output.
- Improved paragraph alignment detection, including two-line centered titles, first-line indent and hanging indent paragraphs.
- Improved list recognition: bullets on the same line as body text, sub-items marked with dashes, ordered-block truncation and lettered number chains.
- Improved list numbering, hanging indents, tabs after numbers and continuation line positions.
- Fixed loss of images in tables, duplicated borders, double-line headers, wrong shading ownership and baseline offsets of paragraphs in cells.
- Fixed ownership of rotated tables and side-note text.
- Fixed vector artwork such as comic illustrations being misrecognized as tables.
- Fixed unexpected line wrapping caused by tight text box and column widths, and images being shortened by size rounding.
- Fixed dashed lines being split into many short segments, and whole groups of shapes being converted to images after exceeding the shape limit.
- Fixed banner images covering text above them, and paths extending beyond the page being lost.

Fonts:
- Fixed named styles of variable fonts not being recognized, which caused body text to fall back to another font.
- Fixed missing characters for compatibility ideographs.
- Fixed oversized superscripts and subscripts adding extra line breaks.
- Fixed the space after "f" being squeezed.
- Improved bold and italic detection: it now follows the text's own source font instead of inheriting from neighboring text.
- Improved matching of non-embedded CJK fonts to installed fonts by name.
- Improved the Wingdings diamond symbol, Symbol bullets and spaces at Korean punctuation.
- Improved cross-platform font measurement consistency.

PDF to Excel:
- Fixed numeric cell detection and write-back being affected by the system locale.
- Fixed grouping of fill-in underlines with the following text on the same line.
- Fixed page margins being added twice to column widths and row heights.

PDF to Searchable PDF / OFD:
- Fixed glyph positions and the left boundary of the first character in the transparent text layer.
- Fixed character spacing overflow and broken table backgrounds in non-transparent searchable PDF.
- Fixed source images, annotation appearances and path graphics being extracted twice when an OFD page is carried by a full-page image.

PDF to Markdown:
- Fixed stacking of clipped graphics, total width of double-line borders, redundant white backgrounds and table borders.
