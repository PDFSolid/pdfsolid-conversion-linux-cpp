static base::ErrorCode pdfsolid::conversion::CPDFConversion::StartWordToPdf ( const char *  file_path,
const char *  output_path,
CConvertCallback *  callback = nullptr,
char *  diagnostics = nullptr 
)
static

Starts the conversion of a Word document to a PDF file with default options.

Parameters
[in]file_pathThe input Word document path.
[in]output_pathThe output PDF path.
[in]callbackOptional callback for tracking conversion progress and controlling cancellation.
[out]diagnosticsOptional caller-allocated buffer of 8192 bytes that receives UTF-8 diagnostic text. The first line is "output=produced" or "output=not_produced"; each following line is one "feature:reason" entry, reported once per feature. The buffer is set to an empty string when there is nothing to report. The SDK never allocates or frees it. Pass nullptr if not needed.
Returns
base::ErrorCode indicating the success or failure of the operation. Returns e_ErrUnsupportedFeature when the document uses features that may affect fidelity; the PDF is usually still produced in that case. A real conversion failure returns its own error code, which takes precedence. Returns e_ErrOutOfMemory if the diagnostics do not fit in the buffer.

Starts the conversion of a Word document to a PDF file with options.

Parameters
[in]file_pathThe input Word document path.
[in]output_pathThe output PDF path.
[in]optionsbase::ConvertOptions for conversion settings. Word to PDF uses page_ranges and word_pdf_bookmark_mode; the other options do not apply.
[in]callbackOptional callback for tracking conversion progress and controlling cancellation.
[out]diagnosticsOptional caller-allocated buffer of 8192 bytes that receives UTF-8 diagnostic text. The first line is "output=produced" or "output=not_produced"; each following line is one "feature:reason" entry, reported once per feature. The buffer is set to an empty string when there is nothing to report. The SDK never allocates or frees it. Pass nullptr if not needed.
Returns
base::ErrorCode indicating the success or failure of the operation. Returns e_ErrUnsupportedFeature when the document uses features that may affect fidelity; the PDF is usually still produced in that case. A real conversion failure returns its own error code, which takes precedence. Returns e_ErrOutOfMemory if the diagnostics do not fit in the buffer. Returns e_ErrPDFPage if page_ranges selects no existing page.
