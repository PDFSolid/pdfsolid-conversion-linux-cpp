Detailed Description

Manages all operations related to the SDK library.

The LibraryManager class serves as a central hub for managing the lifecycle of an SDK library. It provides functionalities such as initializing the library with specified resources, verifying licenses, installing fonts, setting up logging and progress callbacks, retrieving version information, and counting pages in documents.

static

Initializes the SDK library with the given resource path as a C-string.

This method should be called before any other SDK function is invoked.

Parameters
[in]resource_pathPath to the resources needed by the SDK (UTF-8). It is not a font source: the converter only picks fonts the reader of the output can also draw, so fonts are taken from the system font directories only.
[in]scan_office_fontsTrue to also scan the font directories of Microsoft Office: Word's application bundle and the Office cloud-font cache (the one-argument overload passes true). On macOS that cache lives in another app's container, and reading it makes the system ask the user to allow access to other apps' data; pass false to skip those directories and avoid the prompt.

Merges Document AI components from the provided model package.

Each call loads only the capabilities contained in the given package and merges them with the capabilities already loaded instead of replacing them. If a package fails to load, the capabilities already loaded are kept.

Parameters
[in]file_pathPath to the Document AI model file.
[in]gpu_idWhich GPU to use for the AI model. -1 (default) means disable GPU.
Returns
base::ErrorCode indicating the success or failure of setting the model. Returns e_ErrInvalidArg if file_path is null or empty, and e_ErrConverting while conversion tasks are running or a release is pending.
