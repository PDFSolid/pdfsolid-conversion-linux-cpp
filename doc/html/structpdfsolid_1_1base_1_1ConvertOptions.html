◆ custom_page_width

float pdfsolid::base::ConvertOptions::custom_page_width = 0.f

Specify the output page width in points (1 pt = 1/72 inch), or 0 to not specify one. Set together with custom_page_height to choose the page outright, which takes precedence over enable_auto_page_size. The size is used exactly as given, orientation included, and the image is scaled to fit inside it without cropping. Only takes effect when the input is an image file. For example A4 is 595.28 x 841.89, JIS B5 is 515.91 x 728.50.

◆ table_recognition_accuracy

TableRecognitionAccuracy pdfsolid::base::ConvertOptions::table_recognition_accuracy = TableRecognitionAccuracy::e_Balanced

Table recognition accuracy. e_Balanced works with the base documentai.model; e_HighAccuracy requires the table_legacy.model package. If the model of the requested accuracy is not loaded, the conversion still succeeds, but tables are recognized with the rule-based method instead, so the result differs.
